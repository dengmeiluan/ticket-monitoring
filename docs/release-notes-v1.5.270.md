# ticket-monitoring 1.5.270 · 2026-10-21

关注航班监控台与航班维度历史落地，品牌语义层统一，并收口全站对齐、遮挡与公开发布面。

## 关注航班台
- 监控页新增「关注航班」一级 tab：航线/日期清单（同宽可选卡）→ KPI（关注/监控中/目标达标/渠道覆盖）→ 全宽走势（折线/K线 × 48h/7/30/90/180 天）→ 聚焦指标+渠道覆盖+目标跑道 → 航班名册（状态/目标/航司/直飞中转/时段/舱位/渠道/价格筛选与排序，行内展开）。
- 折线只画真实采集点；K线为**单渠道×单舱位×单日**真实 OHLC（副标题标明渠道/舱位），与 DB 逐根核对；长窗缺失日使用 `flight_daily` 日桶并标注日聚合；不补点、不插值。
- 目标线、最低/最高/最新点、悬停读数、渠道逐项价格/未供、检索台定位同屏可溯。
- 关注走势悬停改为整图重绘后再画一条十字线，移动鼠标不再累积虚线拖影。

## 配置与数据
- 配置中心「航班监控」独立编排：出发/到达城市联想（中文/拼音/三字码，鼠标+键盘）、日期、真实候选航班卡、监控渠道、目标价快捷、达标提醒、备注、启停；编辑只改口径不换身份。
- 全航线采集新增 `flight_daily`：每次扫描把**所有被采到的航班**按平台/舱位/日 OHLC 落库，不依赖关注配置；raw 明细清理后长窗仍可回放。数据回填 15,876 行/12 天，折扣类舱位 0 行。
- `/api/srx/flight/trend` 任意航班历史接口；检索列表每行「航班历史」无需关注即可试看，banner 明示未写入关注清单。
- 关注目标提醒接入扫描轮尾：真实 current 核对、`alert_state` 去抖（同价不重推、续降≥￥10 补推、回到上方重置）；跳过过期日期与 6 小时前旧采集；坏 target 单条跳过。

## 正确性收口
- 舱位只认中文大类/显式舱位码，折扣/机型/余票标签不再写成舱位身份；手填身份时刻补零、城市归一三字码、跨天归一。
- 扫描后同时刷新今天/昨天航班日桶（跨午夜不丢点）；日桶 400 天自清；raw 查询保留最新 12000 行后回正序。
- 127.0.0.1/localhost 控制台链接不再写进手机推送；旧关注文件无 notify 字段默认开启。

## 品牌语义层
- 5 个渠道（去哪儿 / 携程 / 途牛 / 飞猪 / 同程）使用官方 App / 官网稳定标识；移除活动期促销横幅后裁切为方形 App 图标，27px / 18px / 16px / 13px 分档使用。
- 14 家主流航司（MU/CA/CZ/MF/9C/HO/HU/3U/ZH/SC/KN/NS/GJ/TV）使用官方 App 图标，以**圆形**承运人语义呈现；36 家航司保留中文名与品牌色 IATA 兜底圆形码，未收录者不冒用其他航司图标。
- **形状即语义**：渠道 = 方形 App tile，航司 = 圆形头像；价格、时刻、舱位、状态继续使用各自既有语义，不把身份、价格和状态混成同一种色点。
- 覆盖检索列表、五渠道镜像、来源卡、航班 × 渠道矩阵、同班比照、解析详情、关注航班台（图表读数/焦点条/名册/渠道覆盖）、校准册、配置台候选航班、关注清单、渠道开关、总览关注卡；K 线/折线悬停同步显示。
- 全部以 base64 PNG 内嵌在页面中，**零运行时外链**；未知航司退回 IATA 圆形码，避免错标。
