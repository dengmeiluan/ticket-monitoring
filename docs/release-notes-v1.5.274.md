# ticket-monitoring 1.5.274 · 2026-10-22

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 国内航线与国际航线（五洲目的地）同一套采集-判定-推送链路。
> 数据留在本机，配置全在网页，开源免费。

## 明细与窄屏布局

- 明细表在 761–900（平板/窄窗）也转为三行卡片：价格 / 航班+属性 / 起降。9 列 nowrap 表实测需要约 971px，768 平板容器只有 672px，旧版七列被裁且没有横滚提示；现在 768 与 390 使用同一信息层级，表头、横滚提示一并收起。
- 无结果/空态行补回块级布局：筛选无匹配时不再塌成零高；文案按抽屉真实开合态给下一步，不再用「右上」等方向词（390 档筛选钮在条首）。
- 关注表单页脚退出视口吸底：滚动填表时不再持续遮住舱位/渠道/开关行；390 档主操作全宽、次操作二等分，桌面保持同一行。
- 关注表单城市选择补齐「浏览全部 N 城」：空输入先给热门城市，一键展开按国内→港澳台→亚洲→欧洲→北美→南美→大洋洲→非洲分组全部城市，输入关键词可继续过滤，与配置页的全量选择能力对齐。
- 编辑关注时身份字段显式置灰为只读，打开即聚焦唯一可编辑的目标价；取消/移除后焦点归还「添加航班监控」。
- 提交校验错误落到常驻页脚并聚焦首个问题字段，不再只靠 3 秒 toast。

## 视觉一致性

- 渠道色收敛为单一真源：`--c-*` 主题令牌供图例、脉冲、芯片共用，`SRX_PLATS` 引用同一组 token；「去哪儿=青 / 携程=蓝 / 途牛=绿 / 飞猪=金 / 同程=紫」在检索、配置、关注、图表四处同名同色，暗色主题同步换档。
- 检索芯片与配置芯片统一选中配方：3:1 可交互描边 + 8% 品牌底；渠道名不再继承拉丁字距。
- 页面级操作统一 32px 高与 9px 圆角（概览、检索、走势、配置同一档），紧凑工具条内的 26/27/28px 变体保留。
- 关键控件描边改用 `--ctlbd`（tab、header 图标钮、行内走势入口、检索/配置渠道芯片），容器仍用发丝线，交互边界与分区边界不再同灰度。
- 配置候选「CZ3524/CZ3081」不再截断：显示首段 + `+1`，完整身份进 title；多航段在同一张卡内也不再换行错位。
- 分页 KPI 脚注允许两行，390 不再把「用时/覆盖」省略成无 title 的省略号。

## 数据诚实与追溯

- 日历/薄行不再落 `near/brk`：只有一条渠道最低价、没有航班身份的日历行，不会在价格上出现破线描边或擦边暗示。
- CSV 状态列补齐「仅观察 / 未设心理线 / 日历价不参与」，与界面、镜像、证据口径一致。
- 移动明细卡把「补位 Nh」与「经 X · 衔接 Y」带入 meta 行：桌面渠道列与衔接列在卡片化后不再丢信息。
- 关注卡 DB 端点同样过 6 小时时效门：断供一天的关注仍显示当前最低价，但不再判「已达标」，文案改为「缓存 Nh · 不判达标」。
- 镜像详情到达时间不再出现「++1」：跨天标记按原词面渲染一次。
- 全部用户都未设心理线时，顶部状态从「未达标」改为「仅观察 · 未设心理线」，不暗示一个从未配置过的判定。
- 健康页在 390 激活时补滚到最新一轮；隐藏容器中 `scrollWidth=0` 导致的「最新轮次藏在屏外」修复。

## 图表

- 走势图横轴域跟随实际观测跨度（加小幅留白），30 天窗口只有 14 天数据时不再把一半画布留空。
- 1–2 天跨度的时间轴带日期；K 线日 OHLC 优先取官方日桶，缺日桶时才用裸采集点聚合，不再用首个点伪造全天。
- 渠道色与关注台、检索台统一，K 线、折线、图例不再与芯片撞色。
