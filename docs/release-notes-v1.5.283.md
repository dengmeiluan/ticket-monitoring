# ticket-monitoring v1.5.283 · 2026-10-22

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 数据留本机，配置全在网页，开源免费。

本轮是 v1.5.282 之后八路审计的 P1 收口，重点是把「监控可编辑、舱位不串语义、班次不虚增、健康分母不说谎」四处从界面到服务端打通，并把仓库历史与发行产物收敛为每个版本一条痕迹。

**关注航班可编辑**
- 关注台/总览卡「编辑」不再静默无响应：配置清单未加载时先强制读取，仍缺失则注入当前关注，编辑表单必定打开。
- 编辑态身份字段（航线/日期/航班号/起降时刻/舱位/经停）全部可改，取消「移除后重加」的旧约束。
- 服务端 update 携带身份 patch 时重建 `flightKey` 与关注 id；目标身份已在清单中则拒绝重复并提示直接编辑该条。新身份从零累计，旧身份采集记录仍留在明细/走势可回放。
- 配置导航补 `:focus-visible` 焦点环，键盘用户不再丢失当前位置。

**舱位语义单源**
- 状态层新增 `cabin` 真实舱位（`cabin_clean` 清污 → `cabin_class` 归舱系），`cabinT` 仅作「舱名·折扣·机型·行李」描述串。
- 明细镜像、三方对齐、CSV「舱位」列只消费 `cabin`；去哪儿 H5 无舱名时的「空客320(中)」「10折」不再冒充舱位，显示「—」。
- 列表舱位片优先真实舱位，完整描述串进 title；舱位筛选与舱等归一同步优先 `cabin`。
- state schema 升级 `probe-r365-1`，旧磁盘快照不会顶替新字段。

**班次与健康口径**
- KPI「N 个航班」与列表「班」去重改用 `srxFlightKey` 同源键（航班号+日期+起降+中转/跨天/经停），渠道名差异不再把同一航班拆成多班。
- 健康徽标与 tooltip 统一 `detOk/att`：仅日历轮计入分母、不计成功，不再出现徽标 50/82 而 tooltip 50/57 的双口径。
- 深色实心选中底改用 `--fill` 深蓝，白字对比达标；矩阵搜索「查看」按钮同步收深。


**全站扁平 UI 与检索性能（r364）**
- 全项目统一「微信式扁平」表面：画布/白面/发丝线三层，卡片去边框，顶部栏收敛为单行、移动端两行（品牌/工具 + 倒计时），主导航与视图切换器改为轻轨白片，按钮/输入框按内容定宽。
- 检索台首屏重排：动作收进「更多」，首屏只留航班监控/校准册/刷新/配置航线；五源条、KPI、筛选与列表字号上调到可读档，空态/加载态不伪造；1360×900 首条完整列表行进入首屏。
- 关注航班首屏竞态修复：配置未就绪不再把 0 条写成已加载；骨架、300ms 重试与强制刷新保证进入「配置 → 航班监控」即显示真实关注。关注台走势增加硬超时与 N/M 进度，单条历史不无限等。
- 官方图标：航司圆形官方图标 87 档 + 机型真实机族上视剪影（空客/波音/商飞/巴航/ATR）进入列表、明细、关注台、配置候选与总览；机型/航司图标与文案之间保留固定间距，多视口几何审计无遮挡/溢出。
- 检索性能：官方图标改为 Blob URL 复用（首屏行 HTML 从 8.6MB 级降到 140KB 级，重渲染 167.7ms → 9.4ms 级）；首屏列表桌面 50 行、≤1100 窄屏 24 行，镜像 10 行（再看 10 行），均按 50/24 行分页「加载更多」，清筛选回填不再一次铺 200+ 行；移除顶栏毛玻璃、逐图标 drop-shadow、图标伪元素高光/多层浮影、重复快览按钮与行 hover 过渡；10s 状态轮询改 ETag 304，静止窗口不再重解析 4MB JSON。
- 去哪儿取数：H5 未命中时默认不再等待已停服的 PC 入口（原 3 采样 × 等待≈72s/日期），直接走 token 直连；PC 复活探测保留 `PC_PROBE_ON_MISS` 显式开关。
- 冻结范围收敛：页面滚动时只有控制台顶栏保持吸顶；检索台「概览/筛选」按钮行、「解析列表/镜像」视图行与镜像面板均随页滚动，不再悬停遮挡内容。
- 渠道健康页「来源接入」由整宽三块说明卡收成一条去哪儿取数状态带：桌面 44px 单行（PC 停服 → H5 可用 → 登录态），390 两行 145px；长说明折叠到「说明」，日期/登录细节进 title，状态与两个动作始终可见。
- 空结果路径减负：行渲染复用同一份筛选结果、空结果跳过同班索引，镜像渠道计数由每渠道重扫改为单遍；空筛选渲染 34.8ms（4× CPU 口径），桌面清筛选回填 50 行 53.5ms（1× 口径），无 100ms 级长任务回潮。
- **本地 8765 真实数据验收（最终源码）**：桌面首屏 50 行 / 镜像 10 行；列表滚轮 112 帧平均 16.7ms（0 帧 >25ms）；空筛选后滚动 125 帧平均 16.7ms（0 帧 >25ms）；390 与 1024 在 4× CPU 节流下分别为 16.8ms / 17.5ms，长任务 0；无 JS 错误。页面/状态接口 warm 读取 11ms/6ms。
