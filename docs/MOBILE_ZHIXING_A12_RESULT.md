# 智行渠道实测结论（2026-10-27，最终版）

> 前两版结论（「智行只有 32 位包」「装上≠可用」）**已被推翻**。
> 推翻的契机：用户质疑「为什么要运行 32 位的？不是应该推进 64 位吗？」——这个质疑是对的。

## 一句话结论

**智行有 64 位包，只是藏在应用宝的第二个下载链接里；装上 64 位版后一切正常，
机票列表可以完整读出。之前所有的"受限"问题，都是因为我装错了包。**

## 1. 错在哪里（自查）

我此前把「应用宝页面上第一个 `.apk` 链接」当成唯一包，抓下来验出 `lib/` 只有 `armeabi`，
就下了「智行只发 32 位包」的结论。**这是取样错误**：同一个页面上有两个不同的 APK 链接。

| 文件 | 大小 | `lib/` ABI | .so 数 | 运行时 `primaryCpuAbi` |
| --- | --- | --- | --- | --- |
| `954EFC49…apk`（第一个链接） | 88.5 MB | **`armeabi`** | 51（全 ELF32/EM_ARM） | `armeabi` ❌ |
| `03293A45…apk`（第二个链接） | **104.0 MB** | **`arm64-v8a`** | **65（全 ELF64/AARCH64）** | **`arm64-v8a`** ✅ |

> 本地留存路径（2026-10-28 逐个解包复核，数字与上表逐字节一致）：
> `_scratch/mobile_paths/apk2/zhixing_travel_10.25.8.apk` = 88,475,842 B / `armeabi` / 51 个 .so；
> `_scratch/mobile_paths/apk2/zhixing_v2.apk` = 104,041,797 B / `arm64-v8a` / 65 个 .so。
> 注意 `_scratch/mobile_paths/apk/com.yipiao_*.apk` 是**后来的 10.26.0 版、只有 armeabi**——
> 别把那些当成本节的 64 位样本（体积 79–80 MB，对不上）。

`cn.suanya.zhixing` **10.25.8**「智行旅行」。第二个链接才是主推的 64 位包。

> 教训：应用宝一个应用可能挂多个 ABI 变体链接，**体积不同就是信号**——
> 只抓第一个链接等于随机取样。

| 步骤 | 结果 |

| 运行时 ABI | ✅ `primaryCpuAbi=arm64-v8a` |

| **32 位受限弹窗** | ✅ **完全消失**（此前 32 位包的阻塞点） |
| 首页 | ✅ 酒店 / 民宿客栈 / **机票** / 火车票 四入口 |
| 机票查询页 | ✅ 国内·国际·往返·多程·特价 标签、机场对、日期、`机票查询` 按钮 |
| 查询结果 | ✅ 切到 `CRNBaseActivityV2`，**真实航班列表渲染成功** |

## 4. 一个必须标注的限制（重要）

**列表里的单班票价被遮盖为 `¥3??`**，页面顶部有「登录解锁更低价 / 立即登录」。

| 数据 | 未登录时是否可读 | 说明 |
| --- | --- | --- |
| **日历最低价**（每天一个） | ✅ 可读 | `¥380 / ¥342 / ¥350 / ¥437…`，与列表同页渲染 |
| **单班次票价** | ❌ 被遮（`¥3??`） | 需登录 |
| 航班号 / 时刻 / 机场 / 机型 | ✅ 可读 | — |

即：**未登录可做日历族采集**（每日最低价，属于 `CAL_PATH_FAMILY`），
**要航班级明细价必须登录**——登录走项目既有的「人工接管」边界
（`docs/CAPTCHA_SOLUTION.md`），不做自动破解。

## 5. 与美团对比（同为 Android 15 实例）

| | 智行 | 美团 |
| --- | --- | --- |
| 包 | `cn.suanya.zhixing` 10.25.8 **arm64-v8a** | XAPK，需取 `config.arm64_v8a` 分片 |
| 运行时 ABI | `arm64-v8a` | `arm64-v8a` |
| 实例 | **v0（Android 15 / 16384）** | **v0（Android 15 / 16384）** |
| 登录前可见 | 日历价 + 航班号/时刻 | 首屏权限弹窗 |

**两者可以共用同一个 Android 15 实例**——Android 12 实例（v1）已无必要，可删（省约 4 GB）。

## 6. 复现命令

```bash
# 装 64 位智行（注意用第二个链接，104MB 那个）
adb -s 127.0.0.1:16384 install -r zhixing_v2.apk
adb -s 127.0.0.1:16384 shell dumpsys package cn.suanya.zhixing | grep primaryCpuAbi
# → primaryCpuAbi=arm64-v8a

# 读列表
python _scratch/spike_mobile/read_zhixing_list.py
```

3. 国际航线（页面有「国际」标签）是否同样可用；
