# v1.7.0 · 2026-11-12 · 采集自愈、口径诚实与 App 渠道改造

> **时效边界**：这是 v1.7.0（2026-11-12）当次的快照，其中的测试计数、渠道状态与界面结论**只对那一版有效**；现状以 `main.py` 版本对应的最新 notes 与实机为准。


> 这一版的共同主题：**让"监控"这件事对自己也诚实**——进程死了有人拉起来、
> 界面不再承诺做不到的事、成功率不再把"我们主动不发"算成失败。

## 新增

- **看门狗 + 心跳**：`main.py` 每 30 秒原子写 `data/.heartbeat`；
  `tools/watchdog.py` 判定三态（心跳新鲜=ok / 陈旧但在=卡死先杀再起 / 不在=已退出直接起），
  事件写 `logs/watchdog.log`。实测：轮次进行中杀进程，看门狗 1 分钟内拉起。
- **App 日期视野预过滤**：日期超出某 App 渠道视野（默认 62 天，可按渠道配置）时，
  **规划阶段**就不派它——实测一天省掉 27 次"起来了才发现超窗"的白跑，
  浏览器通路照常接住（同一天入库 5 条价）。
- **采到即落库**：每个渠道完成即写库，不再等整条查询收齐。
  实测：轮次中途杀进程，已采的 12 行仍在库里（此前会整条查询丢失）。

## 修正（口径与诚实性）

- **三率分母**不再把「能力边界（unsupported）」与「我方主动跳过（paced/skipped）」
  算成失败：智行 App 34% → **81%**；页脚同时报出「另 N 条为能力边界/主动跳过，未计入分母」。
- **`paced` 不再记成 `error`**：节流/TTL 跳过曾经抬高错误率、拖低成功率。
- **App 闸门跳过记 `paced`**（不再是 `blocked`）：那是我们在等自己，不是站点在拦。
- **停手文案四处统一**：`停手 7d` / `剩 7 天` / `人工停手 7 天` 一个口径，
  后端日志也从「剩 10079 分钟」改成「剩 7 天」。
- **登录墙建议按渠道类型分口径**：App 说「在手机上打开「去哪儿 App」用手机号登录一次」，
  浏览器才说「去验证」；并且**上次成功之后没再撞墙就不再催重登**。
- **特价雷达不再假承诺**「每 2 小时自动」：没配置就写「自动刷新未启用」。
- **静默窗页头**写真实开跑时刻（如「07:00 开跑」），不再给假承诺。
- **超窗日期预过滤**的规划日志、停手/停服/未在清单等六个状态的口径统一
  落档在 `docs/HEALTH_STATES.md`、`docs/DISPATCH_HORIZON.md`、`docs/CHANNEL_PARKED.md`。

## 渠道现状（发布时）

- 浏览器 5 家（携程 / 飞猪 / 同程 / 途牛 / 去哪儿网页）：正常，携程与飞猪近 24h 100% 成功率。
