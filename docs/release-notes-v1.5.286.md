**统一链路账本**
- 爬虫基类新增 `path_note()`：每次真实走过的 PC / H5 / API / 日历尝试记录路径、状态（明细/无结果/需登录/人机验证/超时/失败）、行数、日期、耗时与原因；只记代码真实走过的路径，不按结果反推。
- `/api/probe/task` 逐渠道返回 `paths`，任务事件实时追加「链路 PC/H5 …」阶段；探针面板在渠渠道芯片下方展示本腿全部路径尝试，终态渠道状态条对失败渠道直接显示「链路 H5 需登录 / 人机验证」等原因。
- 探针浏览器并发从五路同开降为按优先级两两推进：保留并行加速，同时降低同 IP 多浏览器指纹叠加触发验证码的风险。人机验证/登录墙统一记为 `blocked/login`，并提供「渠道登录」可见窗口供人工完成验证，不做自动绕过。
- 同程、途牛、飞猪国内空结果新增页面级验证码/登录识别，不再把验证页误报为“无票”。
