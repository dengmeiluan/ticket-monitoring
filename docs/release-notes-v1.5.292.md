# ticket-monitoring v1.5.292 · 2026-10-24

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 国内航线与国际航线（五洲目的地）同一套采集-判定-推送链路。
> 数据留在本机，配置全在网页，开源免费。

本版把「关注航线 / 关注航班 / 特价雷达」收进用户级配置，并补齐五大官方渠道的逐日低价来源。

## 用户级配置与监控
- 配置页 C 区更名「关注航线」；D「关注航班」的清单/筛选/表单内联在用户卡内，不弹层、不跳转。
- 监控台单用户也常显「👤 用户 · 用户视图」chip；多用户加「用户：」pills 行；tab 为概览 / 特价雷达 / 关注航线走势 / 关注航班走势 / 关注航班明细 / 渠道健康。
- 明细页新增「只看关注」，按当前用户关注清单过滤本轮真实明细；切用户自动复位。

## 特价雷达：五家官方渠道
- 携程：单航线低价日历 + 全国榜。
- 去哪儿：官方 H5 特价深链，页面 JS 生成签名；使用已保存会话读取真实响应，不逆向签名、不绕过验证码；风控失败冷却 10 分钟。
- 飞猪：单航线 `cheapestCalendar`（含税，7 天窗）；65B 软拒回退国内出发榜并冷却 60 秒。
- 同程：`queryCalendarLowestPrice`（免登录/免签名，国际 90 天、国内 180 天）。
- 途牛：国内官方 H5 同源逐日日历（`type=1`，裸价不含税）；国际无官方日历，如实 `empty`。
- 同条件成功结果缓存 3 分钟；点最低价日期进入真实明细探针。

- 取消后的晚到响应隔离，已收成功结果保留。
