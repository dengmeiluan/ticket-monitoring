# 本轮能力发布说明（r1063，2026-11-08 → 11-09）

> 面向"看得懂业务、不一定要读代码"的读者：**这次到底多了什么、怎么用、边界在哪。**
> 每条都附真机实测证据或命令，不写"应该可以"。

## 一、一句话概括

把"**每个渠道 × 每个维度 × 每条通路**"的数据采集从"能跑"推进到"**看得见、量得出、配置得了、干预得到**"，
并在 App / 浏览器两类登录上都做到"**登一次就自动生效**"。

## 二、新增的六条通路能力

| 能力 | 说明 | 实测 |
|---|---|---|
| 途牛「国际 PC」 | 走 `/intl/list/` 真页面，绕开 H5 接口的 710114 登录门 | 30 分钟出 108 行 |
| 途牛「PC·周历」 | "列表空 ≠ 没价"：抓顶部跨日期低价条 | SHA→BJS 列表无航班仍取到 ¥388；HAK→SHA 2027-02-14 ¥1750 |
| 携程「PC·周历」 | 同上，国际 7 天 / 国内 7 天 | SHA→TYO ¥1200 / SHA→BJS ¥400 |
| 飞猪「PC·周历」 | 仅国际（国内页无此结构） | SHA→TYO 11-16 ¥282 |
| 携程 App 日期自校正 | 要 16 号点到 23 号（差一整行）→ 按行高回退重试 | 日志「实际 23 天，目标 16 天 → y 上移 1 行」，日期这步通过 |
| App 连续超时熔断 | 连续 3 次未出结果 → 暂停 30 分钟（省设备时间） | 3 次后 `app_stall` 1800s，成功即清零 |

> 口径提醒：`PC·周历` 给的是**票面价（未拆税）**，列表/接口给**含税价**。
> 命令行用 `--dates` 看时会标 `*`，避免混比。

## 三、登录：从"用完就丢"到"登一次全家生效"

- **双端各一格、各端独立 profile**：`ctrip` / `ctrip_h5` / `tuniu` / `tuniu_h5` …（与飞猪同款，消除"两个格子一份 cookie"的歧义）；
- **登录成功即清墙**：浏览器侧、App 侧都做了——不再出现"登了还显示需登录 N 分钟"；
- **登完立刻后台复探**：不用等下一轮调度；
- **手动一键清墙**：`POST /api/channel/clear-wall`（非破坏性，只清记忆）；
- **App 登录期间采集让位**：定时轮次不会再把 App 切走（以前会，表现就是"点开后画面没了、存不下来"）。

## 四、观测与建议：五把尺子 + 一条自动诊断

```bash
python -m core.baseline                    # 基线快照（今日出数/通路效率/失败面/登录/降级/计时）
python -m core.channel_matrix              # 每家每条通路：状态 · 成功率 · 最后原因
python -m core.channel_matrix --trend --hours 6   # 每小时产出（改动到底有没有变好）
python -m core.channel_matrix --dates      # 渠道 × 出发日期：哪天没价、是列表类还是日历类（*=票面价）
python -m core.channel_matrix --slider     # 验证战果：次数/今日/连败/冷却/分类成功率
python -m core.channel_matrix --login      # 该登哪一格（端 · 状态 · 入口 · 是否要登录）
python -m core.advise                      # 自动诊断：现在最该做什么（只读）
```

`core.advise` 有三条硬判据（都是踩出来的）：
**能力边界不算被拦**（"远日期不查"不是故障）、**样本 <3 不算结论**、**已退役渠道不算今天被拦**。

## 五、零配置 / 傻瓜化

```bash
python -m core.bootstrap          # 自检→修可修的（依赖/内核/配置/目录），并给下一步

```

只做"机器能不能跑"的事，**绝不碰账号、登录、策略、订阅**（有测试钉死这条边界）。

## 七、边界（诚实写在明处）

| 现象 | 结论 | 依据 |
|---|---|---|
| 携程 App 登录 50003 | **账号 × 设备**组合被判风险；换设备身份无效（两台不同设备都 50003） | 双设备对照，见 `docs/APP_RISK_VERDICT.md` |
| 飞猪 App"一点机票就重启" | App **主动退出**（无 tombstone/SIGSEGV），比弹滑块更硬 | 实测 |
| 阿里 NC 滑块 | **强人机验证，不硬刚**（用户明确要求） | 简单滑块/算数/文字类已支持自动尝试 |
| App 通道要彻底通 | 只有**真机**（模拟器有 ARM 翻译层痕迹） | `docs/APP_RISK_VERDICT.md` |
| 夜间 01:00–07:00 | **采集与推送一起停**（运营决定，用户拍板） | 见能力文档"夜间静默窗是运营决定" |

## 八、什么时候看哪条命令

| 你想知道 | 跑这个 |
|---|---|
| 今天到底采到多少 | `core.baseline` |
| 某家为什么 0 条 | `core.channel_matrix` |
| 改完有没有变好 | `--trend` |
| 哪天没价、为什么 | `--dates` |
| 该不该登录 | `--login` 或 `core.advise` |
| 滑块有没有在工作 | `--slider` |
