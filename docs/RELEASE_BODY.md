> 自托管的多渠道机票价格监控：航班明细采集 → 钉钉图文推送 → 达标四层强提醒。

## 它是什么

一个装在自己电脑或 NAS 上的机票价格监控台。它按你配置的航线、日期和心理价，持续采集 **10 家渠道**的真实航班明细；每一轮把结果聚合成一条钉钉图文，达标时用四层强提醒把你叫醒。没有云端账号、没有自动下单，数据、配置和登录态都留在本机。

- **10 家渠道**：携程、去哪儿、飞猪、同程、途牛 **5 家浏览器渠道**；智行 App、去哪儿 App、携程 App、同程 App、飞猪 App **5 家 App 渠道**（可选，默认关闭）。
- **国内 + 国际**：同一套采集、判定、推送链路；国际覆盖五洲目的地。
- **7 个采集维度**：国内、国际、日历、明细、往返、多程、低价机票。
- **10 渠道 × 7 维度能力矩阵 + PC/H5 端面**：每格三态（已验证 / 渠道没有 / 产品支持但采集端未实现或当前风控未出数），悬停写原因；App 渠道相对浏览器端的缺口单列。
- **11 条平台质量轴**：可配置、可观测、可干预、可见性、可溯源、可识别、可区分、可幂等、语义清晰、可指导、可判断；**10 家 × 11 轴**由契约门禁逐格求值。

## 能做什么

- **真实明细采集**：价格、航班号、起降时刻、中转、跨天、时长、航站楼、舱位、机型、准点、行李；每次全航线采集同时写入 `flight_daily`，不依赖是否关注。
- **监控与判定**：多用户、多航线、多日期（区间/指定日，双草稿保留）；直飞/中转独立心理线；航司白名单（`!` 排除）、行李、时段、衔接、直挂、跨天、价格上限、最长时长等门禁；航线可暂停不删除；关注航班是已配置航线/日期明细中的指定航班子集，可单独编排渠道、目标、提醒和备注。
- **推送与提醒**：每轮一条钉钉图文，达标置顶、语义分档、7 天趋势与操作建议；四层提醒——钉钉 @、Windows 弹窗、ntfy/Bark、阿里云电话/短信；支持免打扰、预览和发送历史。
- **页面**：概览、特价雷达、航线走势、航班走势、航班明细、渠道健康六个监控视图；独立真实检索台（价带/渠道/筛选/矩阵/镜像/三重对齐/单条与组合探针/CSV）；K 线、价格日历、登录卡、节流台账、能力对照矩阵。配置全部在网页完成，支持热加载与启动级差量提示；带在线演示站。
- **App 渠道（可选）**：经 Android 模拟器 + adb 采集；不启用时框架完全不碰 App（不 import、不检测设备、界面不显示）。App 登录用内嵌真机画面（近全屏工作台，可专注/缩成浮窗），登录态打包快照，下次采集前恢复。携程 App 国内/国际单程明细与国内/国际往返、同程 App 国际单程明细/国际往返、去哪儿 App 国内往返均已真机跑通；飞猪 App 走固定竖屏 + Windows OCR，仅国内当月单程，连续自动化触发「访问被拒绝」时如实停下、需人工恢复；途牛 App 在 MuMu 上因原生库不兼容暂不支持；美团因人脸核验暂不接入。
- **数据诚实**：拿不到就显示错误/被拦/未验证；`empty` 必须有无票证据；不把单程价相加冒充往返总价；往返/多程返程栏未加载时标 `totalLoaded=false`/`retLoaded=false`，不把半页当完整；不绕过滑块、验证码或人脸风控。
- **后续加渠道**：渠道注册表、能力矩阵、11 轴契约、登录槽位、名称/图标/颜色均按统一入口扩展；新增渠道漏接任一表会被契约门禁点名。新增往返/多程能力按「行级口径标记 + 真实夹具 + 范围短标签」的统一契约接入。

## 快速开始（免装 Python）

1. 从下方「发行资产」下载对应平台包：Windows / Linux x64 / macOS arm64 / macOS x64。
2. 解压到任意目录：Windows 运行 `TicketMonitor.exe`；Linux/macOS 运行 `chmod +x TicketMonitor && ./TicketMonitor`。
3. 浏览器打开 `http://127.0.0.1:8765`（默认监听本机；可在配置里改 `web.host` / `web.port`）。
4. 在「配置」里填航线、日期、心理价、钉钉机器人；到「渠道登录」逐家登录。
5. 等待下一轮扫描；结果会出现在概览、明细与推送里。演示数据可运行 `python webui.py --demo`。

> **App 渠道（可选，默认关闭）**：先在「全局参数 · Android 真机通道」启用并连接本机 MuMu + adb，再到「渠道登录」用内嵌真机画面（近全屏工作台）登录；不启用时 5 家浏览器渠道不受影响，界面也不会探测设备。
