# ticket-monitoring v1.5.282 · 2026-10-22

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 数据留本机，配置全在网页，开源免费。

本轮是 v1.5.281 之后的六路审计收口，重点是把「看起来有数、实际口径打架」的地方改成三处同源，并把首屏与窄屏的焦点/触控补齐。

**数据诚实**
- 舱位以渠道明示词面优先：携程 A/J/Z 等销售运价码不再把经济舱显示成「头等」，明细表与详情、RAW、CSV 四处同口径。
- 健康徽标改「航班级 50/86」：36 轮仅日历价不再从分母消失，不再出现「明细 100%」的假绿灯。
- 航线 30 天日 K 注记补「含日历价」，与折线口径一致；达标 KPI 同时给「6 个航班 · 14 条报价」。
- 关注台/总览的达标仍只认真实、未补位、未过期的航班级行。

**响应与稳定**
- `/api/srx/calendar` 增加 60 秒 + DB 签名缓存：实测 1.10s → 2.9ms。
- `/api/health` 改 stale-while-revalidate + 单飞刷新：日志每写一行 mtime 变化时，8 个并发请求不再各解析 9 秒。
- 首页 3.28MB 内联页按代际缓存并启用 gzip/ETag：压缩后 1.92MB，条件请求 304；HEAD / 探活 200，state 的 304/gzip 补 `Vary`。
- 详情浮层改 flex 纵排：头/页签/复核条常驻，正文内部滚动；1280×900 复核条完整可见，正文滚动位置跨重渲保留。

**可访问性与窄屏**
- 检索层打开时 `/` 不再把焦点拉到背景搜索框；详情页签 Home/End 回焦限定 `.srx-dtabs`。
- 城市面板 Tab 索引回绕 + focusin 兜底，国内/国际为真 `role=tab` 并支持方向键。
- 320 航班列 62→103px（动作列 2×36 网格）；首屏动作条与 7 枚航线 chip 横滚，首行从 y906 回到 y760；校准册轨道移动端不粘顶；移动工具条直达矩阵。
- 矩阵高价价格格回归中性底，不再比选中价更像主按钮；横滚提示只在实际溢出时出现；320/390 脉冲柱 24px 触控格。
