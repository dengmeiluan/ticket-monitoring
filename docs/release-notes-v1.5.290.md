# ticket-monitoring v1.5.290 · 2026-10-23

本版在 v1.5.289 之上继续收口：检索筛选从长下拉墙改为带计数的分组卡片，补齐多选与精确时间；关注航线/关注航班/概览走势统一迷你曲线口径与目标线，修正收起态和移动端可达性；关注航班的航线摘要严格按航班日期匹配，不再借用其他日期。

## 检索筛选

- 共同筛选：航司、出发机场、到达机场、舱位、机型改为多选标签，显示忽略本组自身条件后的分面计数；航司支持中文名/代码搜索；零结果选项灰显。
- 共同组仍含共享/经停/风险三种口径、起降时段、价格带、行李/餐食/廉航/跨天/隐藏日历价；起降支持 `00-06` 时段和精确到分钟的起止时间。
- 加工与历史：中转/飞行时长、准点、机龄、托运、机型、仅大型机、儿童、余票紧张。
- 检索特有：有原页、有 raw、仅缺失、字段齐全、隐藏补位、仅达标、隐藏限购/高风险价；「清除共同筛选」保留这些条件。
- 快捷预设：直飞含行李、白天出行、省心出行、只看达标。
- 分组卡片头/尾实时显示「命中 N / 总数 M」；「更多筛选」切换为「收起筛选」并带活动条件数；渠道计数按当前日期/关键词/其他筛选计算，避免点进零结果。
- 「清除全部」同时清除日期与结果筛选（任务日期快照除外）；面板底部在手机端吸底，保留清除与收起。
- 手机端筛选面板改为单列卡片，展开时自动打开筛选上下文并把面板滚到可视区。

## 曲线与关注

- 迷你曲线统一按自然日取当日最低价，图例按唯一天数显示（不再把原始采集点叫作“采集日”）；缺失日期断线，不再跨日拉平。
- 关注航线、关注航班、概览卡统一目标线为红色虚线；远低于/高于数据区的目标不再把整条曲线压扁，图例标注「超出视图」。
- 关注航线走势与关注航班走势统一为逐点折线，不做过冲平滑；航线图新增「极值」开关：默认隐藏 IQR 离群价并在图注说明，点击可显示原值。
- 关注航线卡改为等宽自适应网格（1360 三列），去掉最后一张全宽的特例；卡脚显示唯一天数。
- 关注航班顶端航线摘要只匹配同一航班日期；没有同日配置时明确显示未配置，不再借用相邻日期的阈值和曲线。
- 关注航班停用/过期/范围外文案改为独立实体口径，不再写“关注航线子集/扫描渠道”。

## 探针与移动端

- 收起探针后保留「展开」按钮（修复 `.srx-probeacts` 被整体隐藏）；平板/手机收起态保留草稿摘要。
- 收起时同时隐藏组合面板；清空组合会关闭组合面板。
- 手机端探针渠道片不再撑出卡片，任务数字允许换行；渠道登录按钮在状态条内吸右，避免滚出屏幕。
