# ticket-monitoring 1.5.268 · 2026-10-21

五路并发审计后的 UI 遮挡/对齐收口，并在同一版本落地「关注航班监控台 / 航班维度历史」新能力。

## 登录/配置卡
- 登录卡 hover 只换边不位移；显式 5/3/2/1 列，卡片同顶等高，按钮满宽等长。
- 配置文件卡三动作顶部 `.sh-acts` 全宽等分；元信息四行；路径卡动作三列。
- 航线头 761–1199px 摘要独占整行，标题不再被压成竖排或裁切。

## 关注航班 / 筛选
- 关注航班卡 901–1159px 单列，1160+ 双列用 `minmax(0)`，徽标/按钮不再跨卡；901/1024 无横向滚动。
- 明细筛选机场列改 0.72/1.28，1280/1360 到达机场不再落单、舱位上方无 37px 空档。
- 预设/日期/航线/渠道/摘要标签统一 `--flt-lab` 宽度，首片同一起点；动作组 `.fltacts` 展开“更多筛选”不再换行重排；移动端预留 CTA 高度。
- 5 个主视图 tab 在 ≤760px 五等分单行，390/375 第五格完整、触控高 36px；图例移到预设行后，375 首屏可达。

## 浮层/交互
- 城市面板打开时任意宽度隐藏 savebar；详情/校准册/检索弹窗头部吸顶，滚动后关闭钮仍可见。
- 航班联想 `.airsug` 移到输入框正下方，消除 136px 脱节；toast 在筛选/详情打开时移到左下，`aria-label` 带原始消息；城市面板关闭后焦点回到触发输入框。

## 关注航班台 / 航班维度历史
- 新增监控页「关注航班」一级 tab：航线清单（同宽可选卡）→ KPI（关注/监控中/达标/渠道覆盖）→ 全宽走势（折线 / K线，48h/7天/30天/90天/半年）→ 聚焦航班指标+渠道覆盖 → 航班名册（状态/目标/航司/直飞中转/时段/舱位/渠道/价格筛选与排序，行内展开详情）。
- 走势按真实采集时刻回放；K线 OHLC 由真实采集点按自然日聚合。目标线、最低/最高点、最新点、悬停读数与「日聚合」标记同屏，不补点、不插值。
- 配置中心「航班监控」独立编排：出发/到达城市联想（中文/拼音/三字码，鼠标+键盘）、日期、真实候选航班卡、监控渠道、目标价快捷（当前价/低 5%/低 10%）、达标提醒、备注、启停；编辑只改口径不换身份。试看航班可直接带入该编排。
- 全航线采集新增 `flight_daily` 航班日桶：每次扫描按真实 raw 落库所有被采到的航班（平台/舱位/航班身份 × 日 OHLC），不依赖关注配置；raw 明细清理后长窗仍可回放。新增 `/api/srx/flight/trend` 任意航班历史接口。
- 检索列表每行新增「航班历史」入口：无需关注即可打开同款走势台试看；试看 banner 明示「数据来自全航线采集、未写入关注清单」，可一键去配置关注或返回清单。
- 关注目标提醒接入扫描轮尾：按真实落库 current 核对目标，`alert_state` 去抖（同价不重推、继续下探≥￥10 补推、回到目标上方重置），通知失败下轮重试。
- 新增 `core/flighthist.py` 航班键/舱位单源；`PriceStorage.refresh_flight_daily/flight_history/backfill_flight_daily`；关注台/编排/试看/K线/历史契约测试。
- 数据审计收口：舱位只认中文大类/显式舱位码，折扣/机型/余价标签不再写成舱位身份；`flight_daily` 回填 15,876 行，折扣类舱位 0 行。K线改为单渠道×单舱位×单日真实 OHLC，副标题标明渠道/舱位，不再跨渠道合并出并不存在的开盘/收盘。空舱位历史当前价取同日同平台最低 close，不再按 SQL 行序取任意一条。
- 日桶边界/提醒：扫描后同时刷新今天与昨天日桶（防跨午夜丢点）；目标提醒跳过过期日期、跳过 6 小时以前的旧采集，坏 target 单条跳过不拖垮整用户；127.0.0.1/localhost 控制台链接不再写进手机推送。
- 关注键归一：`_watch_entry` 把 9:55 补零为 09:55、城市名归一到三字码、`+1` 归一为 `+1天`，非法时刻/跨天直接拒绝，避免手填身份与 raw 键静默失配。
