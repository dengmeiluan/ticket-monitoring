## 2. 航司图标（87 个 IATA 码）

- 本地标识：`SRX_AIR_IMG[IATA]`，统一 192×192 PNG；名称/识别色在 `SRX_AIR_META`。
- 用途：检索行、明细、同班比价、走势图例、关注台与配置页的航司身份识别。
- 来源：**部分可核验、部分未逐项留档**。仓库内可确认 17 个来自官方 App 商店截取；其余多数来自维基百科的航司品牌标记。抓取脚本位于未随包交付的 `_scratch/`，因此本清单不能为每个文件声称“官方站点原件”。
- 结论：这些图标按“识别用品牌标记”使用，不宣称全部为官方一手素材；需要法务级授权追溯时须逐项补源 URL 与核验记录。
- 未覆盖并回退 IATA 字符牌的代码：`QF`（澳洲航空）、`LT`、`W1`、`VL`、`EN` 等；未知代码统一回退，不生成近似官方图。
- 代码共享：明细“承运航司”优先使用实际承运代码（`shareCarrier`），销售航司另行标注，避免把销售方图标当成实际承运方。

## 3. 机型资源（22 个机族）

- 本地标识：`SRX_PLANE_MODEL`，项目自绘 SVG 上视剪影（Airbus/Boeing/COMAC/Embraer/ATR 机族），使用制造商识别色。
- 定位：**机族示意**，不是具体机型官方图，也不是制造商 Logo；界面标注“制造商识别色/机族”，不宣称官方精度。
- 体量口径（大/中/小型）与未细分状态单独标注。

## 4. 渲染与回退

- 统一尺寸/比例/留白令牌；图片 `loading="lazy"`（长列表）、`decoding="async"`，Blob 缓存避免逐行 base64 解码。
- 加载失败回退字符牌（航司用 IATA 码、渠道用中文首字），保持行高与文字基线；不出现破图或布局跳动。
- 所有资源随源码/发行包内嵌交付，离线可用；不依赖第三方 CDN。
