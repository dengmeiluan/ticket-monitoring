# ticket-monitoring v1.5.293 · 2026-10-24

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 国内航线与国际航线（五洲目的地）同一套采集-判定-推送链路。
> 数据留在本机，配置全在网页，开源免费。

本版集中收口「数据真实性、关注子集语义、筛选一致性与窄屏可用性」，并把探针失败、登录状态、雷达价格口径全部改成可解释的分型。

## 数据真实性
- 移除去哪儿浏览器指纹伪装（webdriver/WebGL/plugin 覆写）；保留真实页面、可见窗口与人工接管，不绕过验证码或风控。
- 去哪儿超时/网络异常不再判成「登录失效」；携程/去哪儿/同程/途牛按 timeout / error / parse_error / login / blocked / empty 分型落证据。
- 携程与去哪儿收到往返请求时明确返回「往返明细暂不支持」，不再把单程价冒充往返总价；已支持往返的飞猪/同程口径不变。
- 携程机场级航线不再用城市级日历价回填机场航线；国际列表缺日只保留可核对的口径。
- 雷达逐日价携带税口径（含税/裸价/未知），混合口径最低价明确标注「跨口径」；缓存回放原始状态与原因，不把回退/部分结果改写成「成功」。
- 雷达先把机场码归一为城市码；途牛国际不调用国内榜单冒充官方日历；飞猪软拒回退、同程 code=5、去哪儿风控冷却分别如实显示。
- 关注航班的目标提醒改用达标口径 `eff`，与检索台达标标记、关注台和推送一致；不再出现「界面未达标、钉钉却推送」。

## 关注子集与走势
- 关注航班真实继承父航线条件：只要直飞、排除跨天/经停/共享、出发到达时段、航司名单、渠道范围不符的条目判为「范围外」并停止提醒；新增/改身份时直接拒绝。
- 「只看关注」匹配完整航班身份（flightKey 含日期/机场/航班号/中转/跨天/经停）加舱位，再按关注渠道限定；停用、过期、越界关注不再命中；刷新后自动重取关注集合。
- 航线走势与列表/告警共用航线筛选：被列表剔除的直飞/航司/价格/经停/时段/渠道条件不再画进曲线。
- 30/90/180 天长窗日桶也带航线条件；无航班级日桶时不再用未过滤的日历池替代，而是明确空态说明。
- 从概览卡进入关注台时保留卡上的时间范围、清掉不适用名册筛选，焦点航班与图表保持一致。

## 筛选、计数与状态
- 检索与明细统一含行李判据（明示「无免费托运」不算含行李）、共享/跨天/舱位空值律与关键词字段；同一份数据同一组公共条件得到一致集合。
- 计数分开：任务返回只报本次任务行，历史并集单独标注；空态区分未采集、所选日期无数据、所选渠道无数据、只看关注未命中和普通筛选无匹配。
- 首次进入自动定位到有数据航线时明确提示；恢复旧条件提示「已恢复上次筛选」并展示完整条件与一键重置。
- 五个结果开关与「只看关注」进入持久化；重置、计数、筛选摘要同步。
- 探针轮询/恢复增加任务代次与单飞守卫，旧任务晚到响应不再覆盖新任务；切用户清空旧任务、关注与雷达结果。
- 失败重试按腿只携带该腿失败的渠道，不再把一个失败渠道复制到所有航线/日期重复请求；逐腿阶段新增真实“等待响应/接收数据/标准化去重”事件。
- 登录三态分开：已保存、会话/页面已核验、近期明细成功；页面可访问不再显示整卡绿灯。
- 冷启动 `/api/state` 失败结束骨架等待并给重试入口；详情抽屉在上下文变化时关闭并解锁页面。

- ≤540 六视图切换器改为 3×2 网格，320 宽最后两格完整可见；窄屏状态 pill 允许两行且保持 36px 触控高。
- toast 层级统一到登录/推送弹层之上；补齐 `--ok/--bad/--okbd/--badbd/--badbg/--bg2/--soft` 等缺失令牌，错误徽标与任务状态点恢复语义色。
- 城市联想浮层增加水平边界避让；日期带「展开」改为可收起并在换航线/日期时复位；紧凑密度不再裁掉徽标。
- 健康时间线部分/失败/未采改为纹理与描边区分，不再只靠颜色；图例同步。
- 图标加载失败回退到字符牌；明细「承运航司」使用实际承运代码，代码共享不再把销售航司当实际承运。

## 已知边界
- 去哪儿取消浏览器指纹伪装后，风控更严的时段可能降低成功率；这是不绕过风控的诚实取舍，失败会按风控/超时/网络分型显示。
- 携程/去哪儿往返明细仍未实现，界面明确标「往返明细暂不支持」；飞猪/同程往返能力保持。
- 途牛国际无官方低价日历时雷达为空是源侧边界，不等于国际明细永久不可用。
- 飞猪 65B、同程列表签名、携程 H5 30212 等源侧限制仍按既有边界如实显示。
