# ticket-monitoring 初版 · 持续更新

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 国内航线与国际航线（五洲目的地）同一套采集-判定-推送链路。
> 数据留在本机，配置全在网页，开源免费。

> **时效边界**：本文是 v1.5.305 当次发版快照，不是现状——渠道可用性、
> 版本号、测试计数都以仓库 HEAD 与 `docs/EXECUTION_SPEC_LATEST.md` 为准。

**当前版本：v1.5.305 · 2026-10-30**（初版首发 2026-10-23）

本版主线是**接入两个只存在于 Android App 里的渠道**：智行 App 与去哪儿 App。
两者与五个浏览器渠道同权——配置页可勾选、有独立登录入口、有分通路账本、
有健康与干预，不启用时框架行为与以前完全一致。

## App 渠道（本版主线）

**智行 App（`cn.suanya.zhixing`）**
- 未登录即可取日历价（单班价被遮成 `¥3??`），登录后可取完整明细。
- 明细路径修掉四处断点：价格拆成 `￥` + 数字两个节点、弹层价格异步渲染、
  选日必须走弹层、主流程曾拿到日历价就返回。现在同一日期可拿 5–7 条带航班号
  与时刻的真实明细。
- 到达时刻按「同一排」配对（曾因水平距离相近而张冠李戴，造出「到达早于起飞」
  的假行）；列表页「当日低价」卡片的价格不再因文档序间隔而丢失。

**去哪儿 App（`com.Qunar`）**
- **必须手机号登录**：未登录时首页即是登录页，「搜索」与日历「查价」都会跳
  `UCLoginByPhoneActivity`，返回键也退不出去。因此登录是硬前置，未登录一律记
  `login`，绝不记成「没票」。
- 登录后单日期真机采到 6 班真实明细（KN5977 20:45→22:55 ¥1130、CZ8889 ¥1130、
  HO1254 ¥1175、HO1260 ¥1350、FM9102 ¥1400、CZ5663 ¥1540），80 秒/轮。
- 真机修掉三处硬编码：结果页价格列在 x=772–863（原判据钉死 x>=1200，一个价都
  取不到）、首页日期行是中文「10月31日」、目标日=今天时页面只写「今天」。

## 登录（与浏览器渠道同一套心智）

- 两个 App 渠道都走**网页内嵌真机画面**：在配置页点开就能看到模拟器实时画面，
  在页面里点、输、完成，不用切到模拟器窗口。实测取帧 ~0.3s。
- 「我已登录完成」会 dump 首页校验是否真的离开了登录墙——各渠道登录墙形态不同
  （去哪儿是手机号表单、智行是「立即登录」文案），按渠道分别判定，不混用。
- 登录态快照可导出/恢复：去哪儿实测导出 2.8 MB / 2.1s、恢复 2.3s，恢复后仍处
  登录态——登录一次可长期复用。

## 账本诚实性

- 去哪儿**没采到票时不再记 `empty`**：空结果有五六种成因（没打开首页、设城市失败、
  找不到搜索按钮、点搜索无反应、等不到列表页），只有「确认列表页已打开且当天无
  航班」才记 `empty`，其余记 `timeout` 并写明卡在哪一步。
- 「有航班行但全无可用价格」不再回 `ok`——那会让账本显示「0 条却成功」。

## 渠道清单一致性

- 登录分区卡头、健康日志正则、告警渠道名、概览「全线最低」、配置页勾选 chip，
  此前各自写死渠道清单；接入第二个 App 渠道时集中暴露。现在统一从单一事实源
  派生，新增渠道只需改一处。
- 概览卡不再把去哪儿显示成裸 id `app_qunar`。

## 移除

- 按使用者决定**移除美团 App**。该渠道从未落地采集器，本版清掉注释与操作手册中
  的残留表述，渠道清单只保留智行 App 与去哪儿 App。
