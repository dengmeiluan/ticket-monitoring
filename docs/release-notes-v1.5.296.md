本版修复两个持续监控缺陷，并补上回归门禁：

## 修复

- **跨日后雷达自动监控不再停摆**：用户保存的开始日期过去后，自动轮询会把开始日夹到当天、继续监控剩余日期范围；整段已结束时只记跳过原因，不再每 2 小时抛 `开始日期不能早于今天`。手动查询仍保留“开始日不能早于今天”的校验，行为不变。
- **未配置推送通道时不再产生 `NoneType.send` 告警**：渠道登录态告警只向实际存在的 notifier 发送；无通道用户静默跳过，不写无意义异常。
- 新增两项回归：过去开始日夹到当天 / 已结束跳过；notifier 为空不调用 `send`。

## 验证

- 新增 pytest **2** 项；全量 **3699 passed / 6 skipped / 0 failed（收集 3705 项）**。
- live 8765 实测：开始日 2026-10-24、当天 2026-10-25 时自动从 05:41 起取数并写入 **25 条**快照，不再每 2 小时抛“开始日期不能早于今天”。
- 版本 `1.5.296`；Windows 包内可执行 `--version` = `1.5.296`。
- 其余能力与边界继承 v1.5.295：特价监控/提醒、证据诊断、路径级来源、统一视觉与性能门禁不变。

## 边界

- 自动轮询只修正日期范围，不改变用户保存的配置；用户仍可在条件区更新开始/结束日期。
- 无 notifier 时不发送是预期行为，不是渠道恢复或登录态证据。
- 不绕过验证码/滑块/风控；原站对照边界与 v1.5.295 相同。
