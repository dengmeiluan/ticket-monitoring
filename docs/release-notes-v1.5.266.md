# ticket-monitoring 1.5.266 · 2026-10-21

本轮在 1.5.265 基础上继续收口宽屏构图与浮层贴合，重点解决“左侧空带、快捷 chips 行尾参差、城市面板盖住输入框、浮层被 savebar 压住”四类问题。

## 宽屏与组件
- 配置工作区取消额外居中收口，与全局导航同轴、随监控页同宽突破；宽屏不再出现左侧空白带，卡片使用完整内容宽度。
- 航司“常用”快捷 chips 在 ≥901px 改为 `常用 + 8 列等宽` 网格，铺满输入框整行；末片右缘与输入框右缘重合，不再半行悬空或裁切。
- 配置分组头/航线折叠箭头、控制轨道、单位贴盒、全局延迟并排等 1.5.265 收口保持。

## 浮层贴合
- 城市选择面板改为“优先贴输入框下方 + 按可用高度正文滚动”；下方不足才向上，避免 1360×900/700 下翻到视口顶部并盖住触发输入框。
- 面板增加 scroll/resize 重新定位，页面滚动后仍贴合输入框；移动端保持底部抽屉。
- 面板/搜索详情/校准册/检索弹窗 z-index 统一高于 savebar；移动端城市面板打开时临时隐藏 savebar，避免底栏压住城市列表。
- 确认弹窗与重启中心改为固定头尾、正文内部滚动，长文案/长差量不再把底部按钮推出视口。

## 验证
- 定向 pytest：73 passed（版本/配置/航司 chips/检索工作台）；干净全量基线 3178 passed（本轮浮层改动前）。
- uitest：522/522，零 pageerror。
- Playwright：1360×900、1360×700、1793、390；城市面板 `covers=false`（桌面），浮层 z-index=130，savebar 打开时隐藏，确认/重启页脚在视口内。
