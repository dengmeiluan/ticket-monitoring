# ticket-monitoring 1.5.271 · 2026-10-21

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 国内航线与国际航线（五洲目的地）同一套采集-判定-推送链路。
> 数据留在本机，配置全在网页，开源免费。

本版是一次「可读性、可观测性、遮挡与发布对齐」的集中收口：把真实数据下容易发糊的小字、低对比行、浮层贴边和列表首屏问题逐项修掉，并让关注航班台在本地演示与在线演示里都能直接体验。

## 可读性

- 总览关注卡迷你走势不再把 7px SVG 文本压进 48px 高画布：目标线保留，低/高/采集日/目标价下沉到 10px DOM 图例；关注台所有 8px/9px 标签升到 10px，航班名册、目标跑道、渠道覆盖、筛选与操作按钮同步升档。
- 搜索列表补位/日历行不再整行 `opacity:.78`（旧值把 10px 次要文字压到 3.4:1）：改为中性底 + 明确徽标，正文恢复 AA；IATA 兜底角标强制白字；同班比价行不再白字白底；矩阵渠道表头改用正文色，品牌色只留给图标与色条。
- 「行情破线」价格由空心描边改为实心绿 + 点线下划，DPR1 下不再发糊。
- 时长统一为 `X时YY分`（分钟零补齐），列表、矩阵、镜像、详情、比价、关注名册同源；跨天统一显示 `+1` 上标，详情表不再 `+1天` 换行，矩阵补上时长与跨天。
- 分区编号改为「单页内唯一」：概览 01/02/03、走势 01/02、关注/明细/健康各 01；「关注航班」与「WATCH」术语收口。

## 布局与遮挡

- 检索台在 1280×900 首屏直接露出解析列表表头（旧版 grid 顶在 899px，首屏零行）；1683×820 短屏桌面不再误入移动模式，价带/五源/KPI/筛选仍可见。
- ≤1100 的吸顶概览/筛选条与视图 tab 错层排布，不再 40px 完全重叠；≤1400 英雄操作栏右对齐换行，不再左漂留半屏空白。
- 390 弹层统一 12px 边距且页面零横溢；健康表横向滚动收进弹层；城市面板底距 ≥8px、锁定背景滚动、Tab 焦点圈闭、Esc 关闭并归还焦点；城市联想在底部空间不足时自动上翻，配置/检索两处补 `aria-activedescendant` 与 `aria-selected`。
- 重启中心补焦点圈闭与关闭归还；监控表单新增始终可见的「取消」与吸底操作栏；toast 降到浮层之下；移动筛选 Esc 可收起且概览/筛选互斥。

## 可观测性与数据

- 明细表每一行都带走势入口：单启用航线×单日期不再整表失去 📈；暂停/范围外的关注卡也能用「30 天走势」回放真实采集点，不再数据死路。
- J/K 上一处/下一处以当前行位置为锚，raw 异步到达后不再跳到末行；镜像详情的 raw 状态改为「待取」直到真实加载，不再误报未供。
- 演示模式播种 2 个关注航班；在线静态演示补齐 `/api/srx/watch` 与 `/api/srx/watch/trend` 烘焙响应，关注台、总览关注卡、走势与配置台在零安装演示里可直接体验。
- 发布门禁补强：`docs/release_align_check.py` 现在同时校验 `v1.0` 标签目标版本、HEAD 的 CI 结论、README 截图的 git 跟踪、零字节资产与嵌套截图垃圾；CI 的演示路径脱敏门禁同时接受 Windows/Linux 合成根。
