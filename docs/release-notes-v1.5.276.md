# ticket-monitoring 1.5.276 · 2026-10-22

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 国内航线与国际航线（五洲目的地）同一套采集-判定-推送链路。
> 数据留在本机，配置全在网页，开源免费。

## 舱位与关注覆盖

- 去哪儿/飞猪常见的「7折 / 4.7折 / 全价 / 特价」标签现在统一归入**经济舱**：关注「经济舱」时不再只命中携程的「经济舱」行，而是覆盖同班全部渠道的真实经济舱折扣行；纯机型/余票/乱码仍归未知，不强行标注。
- `flight_daily` 日桶与关注台、走势中的舱位口径一致；历史日桶可用 `backfill_flight_daily(14)` 从现存 raw 幂等重算。
- 同班对照、关注台筛选与明细舱位徽标使用同一套语义类（经济/超级经济/公务/头等），不再出现「看板显示同班、关注却只跟一个渠道」的分裂。

## 演示与请求

- 静态演示站禁用「实时探针」入口：演示模式不发起真实外网探针，入口置灰并提示下载源码/zip 后使用；不再让用户点出一个无意义的 400。
- 检索台 `/api/srx/watch` 加载加入在途去重：连续渲染不再并发 10 个相同 GET。
- 健康/脉冲/配置等 >1KB 的 JSON 按 `Accept-Encoding: gzip` 压缩，并声明 `Vary`；`/api/state` 的 ETag/304 与 HTTP/1.1 keep-alive 保持。
