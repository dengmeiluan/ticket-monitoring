# ticket-monitoring v1.5.297 · 2026-10-25

> **时效边界**：本文是 v1.5.297 发布当次的说明，只描述那一版的行为；当前版本以 `main.py` 的 `__version__` 与 `docs/EXECUTION_SPEC_LATEST.md` 为准。文中出现的测试计数、渠道状态、界面截图均为**当次快照**，不得引用为现状。

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 国内航线与国际航线（五洲目的地）同一套采集-判定-推送链路。
> 数据留在本机，配置全在网页，开源免费。

本版集中重做特价雷达的信息表达、渠道登录/入口的扁平组件语言，并修复关注台图例叠字与移动触控/焦点问题。

## 特价雷达

- 新增 `date_series`：每个出发日期一条独立监控曲线，不再只画“全日期最低价”导致假平线；低日红、选中蓝、其他灰，纵轴覆盖全部日期真实价格跨度。
- 曲线末点直接标出“日期 + 价格”（红=最低日、蓝=选中），多线不用猜；悬停/触摸任意点显示日期、价格、渠道、采集时间与口径，提示限制在图内；桌面移出即收起，触屏点按后 2.6 秒自动收起；窗口缩放/横竖屏切换后画布按新宽度重绘，不再拉伸旧像素。
- 新增扁平可展开「采集记录」：最近 8 次运行的时间、状态（成功/缓存/回退/部分/空/失败）、写入行数与说明，运行历史不再只剩一行动态文案；无记录时整行空态；390 下失败/回退说明换行完整显示，不靠悬停；演示库写入 3 条明确标注的合成运行记录，重建时先清空账本，重复启动不叠加。
- 首次/零快照：只保留全宽「设置监控条件」空态，不再渲染空白的走势、低价与来源面板；若已有失败运行，采集记录仍保留供诊断。
- 口径变化不再静默：任一出发日税/裸口径切换时，来源行标“口径变化 N 日”，选中日标“口径较上次变化”，图注标“含口径变化日”，避免把口径跳变当成降价。
- 数据不足时明确“监控次数不足”，不画假走势；图表保留隐藏数据表供读屏读取，并新增“标记”列明确最低日/选中/最低日·选中。
- 日历卡：去掉每格重复“口径未标”，改为 `↓¥40 / ↑¥322 / 持平 / 首次`，低日加“低”徽标，选中态带 `aria-pressed`。
- 低价日卡：日期升为主标题，补“最低日”、较上次价差、渠道；改选非最低日时明确标“选中日 · 非最低”，不再把任意选中日冒充低价日；无真实明细时明确“日历价不能生成航班”，按钮改为“查该日全部明细”。
- 来源只列有数据渠道并标“7 日”，无数据渠道放“未供”行；补最近运行缓存/回退/失败状态。
- 三张卡编号收为 `01 特价监控 / 02 查询与提醒 / 03 官方特价来源`，不再三个 `01`；手动查价降为次级折叠区。

## 渠道登录与入口

- 渠道登录去掉内层白卡与嵌套边框，保留独立会话、登录要求和“弹窗登录/飞猪双端登录”。
- 渠道入口改为一块表面 + 5 行渠道 + 文本路径入口：30 条真实链接全保留，去掉 30 个嵌套边框盒和每格重复边框；1024 两列、390 单列、44px 触控，不供只显示文字。
- 路径仍区分 PC/H5、国内/国际、特价与页面登录要求。

## 组件与移动

- 关注台图例修复 `.mon-legend b` 误伤航班号：`9C6217` 不再被压成 16×3px；图例改两行网格，代码/价格/目标/状态分层。
- 导航计数改为“关注航班走势 · 2”，不再像第二个 tab。
- Section 编号按视图顺序，不再重复；`¥` 价格与 11px 辅助字下限在新增组件内收口。
- 自定义折叠补 `aria-controls`；coarse 指针下按钮/输入/入口 ≥36px；focus-visible 统一蓝环。
- 渠道诊断证据拆为“登录 / Cookie / 最近轮次”三个不拆词标签，窄卡不再把“最近轮次”劈成两行；五卡仍保持按轮次/Cookie 证据分型。
- 检索探针脚注在 390 改为全宽分行：演示说明不再被“渠道入口”挤成 100px 竖排；桌面仍保持说明在左、入口在右。

- 雷达“查询与提醒”的降幅/阈值/冷却改为常显内联标签，数值填入后不再只剩无标签数字；390 门禁覆盖标签可见与不裁切。
- 飞猪双端登录弹窗 390/320 实测完整显示：左右不越界、内容不横溢，关闭按钮与遮罩同步收口；新增门禁覆盖。

- 雷达多线来自本地监控快照，只有持续积累才有走势；首次/单次采集明确提示，不补点。
