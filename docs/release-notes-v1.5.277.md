## 本轮主题：日期身份、舱位口径与浮层秩序

- **全部日期不再偷偷锁定日期**：在「全部日期」下点开任意航班，详情/镜像/对照使用该行真实日期，但顶部日期筛选保持不变；列表、矩阵与镜像在全部日期模式补飞机日期，跨日同班不再看起来一模一样。
- **舱位口径统一**：去哪儿的「7.0折/全价/特价」等折扣描述统一归经济舱；经济/公务快捷筛选、关注同舱匹配、同班矩阵与详情标签使用同一个分类器，不再出现「行是经济舱但经济筛选把它藏了」。
- **矩阵按完整同班组截断**：先生成完整同班组再按上限截取，选中组始终保留；不再把半组切断后把同班另一渠道误判成「未供」，并在底部说明「显示 X / Y 个完整同班组」。
- **关注默认只订阅当前渠道**：列表点 ☆ 不再静默订阅五渠道，默认监控该行来源渠道；其余渠道、目标价与提醒在「航班监控」显式配置。
- **补位阈值修正**：`stale` 是距本次已采的小时数，不是脏标记；0.4h 的无 raw 日线行不再被误判为补位，整条航线的同班矩阵与对照恢复，只有显式补位或 >6h 才进入补位语义。
- **过期/暂停/缓存不判达标**：航班日期已过、暂停、范围外、>6h 缓存的关注显示「不判达标」；配置页关注卡也接入 6h 门；「本轮有价」只认真实 6h 内端点，旧点不再冒充本轮覆盖。
- **配置草稿防丢**：航班监控表单出现未保存修改时，切换用户/航线、刷新清单、清除筛选或 Esc 关闭都会先确认；未保存状态计入全局脏点与关页提示；跨天选项补齐 +4…+7。
- **浮层按顶层栈收口**：弹窗永远压过详情/校准册并使其 inert；Esc 只关最上层；滚动锁改为计数，关闭弹窗不会提前释放仍打开的详情；焦点优先归还精确触发按钮；详情页签补齐 `tablist/tabpanel`、`aria-controls` 与左右方向键。
- **城市键盘完整**：「上海/SHA」这类精确输入不再被当作已选城市而清空查询，方向键不会选到无关热门城；联想与全城面板支持 Home/End、方向键与 Enter，选项不再进入 Tab 序列。
- **演示诚实性**：演示站探针按钮禁用并给出原因；字段健康、五平台校准册、关注台均标注 DEMO 合成数据。
- **公开面**：新增 `docs/index.html`，GitHub Pages 根路径直达在线演示；README 资产体积区间改为实测 58–88MB，补充演示站探针说明与 EN 部署/打包段落。
