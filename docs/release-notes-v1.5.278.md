## 本轮主题：可观测性、数据状态与窄屏完整性

- **全部日期镜像带日期**：镜像列表行在「全部日期」模式补飞机日期，跨日同班不再无法区分。
- **导出状态说真话**：CSV 与证据 JSON 为未设心理线的行明确标注「实时 · 仅观察」；日历补位行保留「日历/薄行 · 补位 Nh」，不再只写「日历」丢掉补位事实。
- **维护中的渠道不再绿色 100%**：字段健康徽标在存在维护轮时降为中性琥珀并显示「· 维护」，tooltip 保留维护轮数；维护轮不计入成功率分母的口径不变。
- **演示健康明确标注**：演示站监控健康页显示「DEMO · 合成健康」，与字段健康、校准册、关注台一致。
- **窄屏完整可读**：320px 详情页签改为两行完整显示；走势 chip 允许换行；关注名册「经济舱」保持整词不拆字；配置候选的舱位/行李元信息不再省略号截断。
- **短桌面保留口径**：1280×800 / 1024×768 继续显示价带「含日历/补位、不当作可出手机票」说明，只收起配置入口，不再把口径一起隐藏。
- **筛选不留孤儿**：筛选/搜索把选中行排除后，详情与镜像自动关闭，不展示列表中已不存在的行。
- **关注台焦点归还**：暂停、提醒开关、移除后焦点回到同一动作或添加入口，键盘用户不再坠到 body。
- **城市分组稳定**：搜索联想按区域稳定排序，组头不再重复；配置全城面板补齐日韩/东南亚/南亚/中东/美洲分组。
- **日历行身份防碰撞**：日历/薄行 rowKey 加入价格，同日同渠道两行不再共用一个选中身份。
