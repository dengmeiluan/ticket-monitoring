## 渠道登录对齐

- 删除登录行内浮动状态圆点，状态改由行左缘 3px 色线承载（绿=近期明细成功、琥珀=已核验/待验证、灰=仅保存）；圆点不再与右侧“弹窗登录/双端登录”按钮基线错位。
- 五条登录行统一三列：渠道名 / 账号与登录要求 / 操作；飞猪双端行同样有状态左线，不再出现一列透明缺口。
- 桌面/390/320 保持行式布局，不返回卡片。

## 数据可见性

- 概览补位窗口从固定 6h 改为随调度周期：`max(6h, min(7d, 周期+1h))`。7 天一轮的配置不再在 6 小时后把整页清空。
- 补位行继续明确标“补位 Nh · 不参与达标”，KPI 不亮达标绿；最后真实采集时间可见。宁缺勿错，不补点、不伪造本轮。
- 版本升级会自然失效旧状态快照，避免旧结构/旧窗口缓存继续顶替新数据。

## 特价雷达走势

- 新增与关注走势一致的档位条：`48h / 7天 / 30天 / 90天 / 半年`，选择即过滤并重绘，记忆上次档位。
- 新增 `折线 / K线` 模式：折线保留逐出发日曲线；K线按最低日（或选中日）的监控快照做逐日开/收/高/低聚合，红涨绿跌，并明确标注“监控快照按日聚合”。
- 数据点密集时画布按点数扩展宽度，走势容器可横向滑动；视口窄时不再把多日曲线压成一团。
- 摘要条继续先给结论：最低价/日期/渠道/较上次/覆盖渠道/监控次数/提醒。
