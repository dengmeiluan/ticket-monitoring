### 仍未修（明早第一件）

`_scroll_calendar` 的**方向与 App 实际相反**——两份取证显示"越滚越晚"：

| 接口 | 作用 | 副作用 |

浏览器入口：面板底部那一行——`版本 vX · 检查更新 · 通路耗时 · 距离分桶`；
有更新时自动变成 `✦ 有新构建 … 立即升级`。

### 本轮新增/改变的口径（容易误读的两条）

1. **`App 登录 xx%`** 是**登录墙探测**口径（每次搜索是否被要求登录），
   **不是账号登录态**——携程 App 搜索强制手机验证码时它就是 0%。
2. **H5 槽位的「明细可用」** 来自该端面自己的通路账本（`entry_path` 以 `H5` 开头
   且真出过数）；不是从"入口页可访问"推出来的。

### 升级（用户不必卸载重装）

```bash
python -m core.update --check      # 有新版本/新构建会说明原因
python -m core.update --download   # 只下载，不动现有文件
python -m core.update --apply      # 备份后覆盖，失败回滚；随后重启
```

面板里同样可以一键完成；`config.yaml` 与登录态（`user_data/`）**永不覆盖**。
