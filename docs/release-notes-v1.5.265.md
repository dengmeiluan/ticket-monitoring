# ticket-monitoring 1.5.265 · 2026-10-21

本轮把配置页与明细筛选从「功能在位」推进到「对齐、对称、可扫读」：统一控制轨道与字段盒，折叠箭头回到右缘，筛选 chips 不再被裁切，移动端动作全部可见。

## 配置工作台
- 配置内容收口为 1320px 居中工作台，页头/主导航保持同轴 chrome；分区内容统一 18/14px 沟槽。
- A/D 区数字字段改为单位贴盒（￥/点/条/天），统一 34px 高、132px 宽、右缘与顶线对齐；D 特价分区改用带边框 fieldset，与 A/E 内容轴一致。
- 分区头与航线头折叠箭头固定在右缘；航线头顺序统一为「摘要 → 操作组 → 箭头」。
- 全局参数「错峰延迟 · 自/至」并排同高；启动级「重启中心」从段头中部移到右缘。
- 工具栏/路径/测试/添加按钮统一 32/34/36px 层级；删除用户/航线/邮箱动作统一，邮箱删除只保留折叠头唯一入口。
- 清除 `.ractions`/`.uact`/工具栏/`.addrbtn` 的旧盒影覆盖，补回可见 focus ring。

## 明细筛选
- 属性筛选改为固定标签轨 + 左右机场双列；出发/到达机场成对呈现，列宽按内容权重 0.9/1.1 分配。
- 航司/机场 chips 改为完整换行，不再用 nowrap 横滚裁切；空分组自动隐藏，选中组标签提亮。
- 时段与价格拆为两条逻辑行；更多筛选动作组右对齐，窄档隐藏尾部排序提示。

## 移动与交互
- 361–760px 操作区四列全可见，≤360px 落 2×2；主视图页签 SVG 化，320px 隐藏图标保四页签同屏。
- 筛选入口在窄档前置，避免唯一入口被横滚裁走。
- 修复折叠头内按钮/开关键盘事件被父级劫持（`e.target!==el` 守卫）。
- 修复 CSV 防注入表达式的跨行裸字符；补 `SRX_CAL_RETRY` 声明；检索 raw 请求去重保留。
