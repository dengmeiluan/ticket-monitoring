# ticket-monitoring 1.5.275 · 2026-10-22

> 自托管的多渠道机票价格监控：五平台明细采集 → 钉钉图文推送 → 达标四层强提醒。
> 国内航线与国际航线（五洲目的地）同一套采集-判定-推送链路。
> 数据留在本机，配置全在网页，开源免费。

## 数据诚实

- 航线级长窗走势不再把日历价标成「真达标」：价格与目标线保留，达标环只由航班级数据承担；图例仍明确「含日历价」。
- 探针在渠道 `extra` 为空时不再把解析值伪装成 raw：该行显示「无 raw · 仅解析」，字段对齐与 CSV 不再声称有原页证据。
- 关注表单同身份重复添加改为明确冲突提示，不再静默覆盖目标/渠道/提醒/备注。
- 关注台数据库端点的 6 小时时效门同样作用于概览关注卡；DEMO 固定快照不套真实断供门。
- 健康「明细成功率」分母排除仅日历轮次：16/18 不再被算成 16/96。
- 补位日历行在 KPI/CSV 中同时保留「补位 + 日历」语义；镜像渠道时效改按本航线最新行计算，不再被其他航线的全局时间冒充「本轮」。
- 日历日期切换时强制关闭旧详情并释放滚动锁，避免显示旧航班、动作却落到新日期第一行。

## 检索与走势

- 概览「走势 ▸」落到当前最优行的航线/日期，不再跳到另一条航线。
- 关注卡新增「监控台」直达并精确定位该关注；跨航线不再落在第一条关注上。
- 走势副标题按实际观测跨度显示「小时/天」；切换范围后采集点标签同步收窄；主题切换会重绘关注走势画布。
- 关注 KPI/图脚把 `等待真实行` 单独计数，达标/接近/高于目标/仅观察/等待之和等于关注数。
- 检索页筛选变化同步重绘镜像；镜像标注「本渠道全量」，不再暗示与筛选后列表同集。
- 移动检索行三个常驻动作提升到 36×36，操作列 118px；筛选/详情/关注不再挤成 27px 小点。

## 配置与表单

- 编辑关注时路由/日期/身份/候选/快捷日期/试看入口全部锁定，并在顶部说明「身份已锁定」；不会出现点候选改了值却保存不进去。
- 起降时刻校验 00:00–23:59（25:99 被拒并聚焦）；航班号校验 `MU541` / `MU541/MU542` 形态；目标价 0 归一为仅观察。
- 暂停/恢复、提醒开关重渲染后焦点回到原动作；刷新清单不再悄悄清空未提交草稿（保留原表单状态）。
- 移动端监控渠道 chip 提升到 36px 触控高度，价格快捷 34px。
- 城市浏览全部仍按国内→港澳台→亚洲→欧洲→北美→南美→大洋洲→非洲分组，空输入先给热门。

## 性能与可访问性

- 服务端切到 HTTP/1.1：`/api/state` 的 ETag/304 条件请求真正生效，浏览器轮询不再每次下载完整状态；302 补 `Content-Length: 0`。
- 检索行动作改为 roving tabindex：不再有 200 个图标各占一个 Tab 停点，行获得焦点后才进入该行动作。
- 指针为 coarse 时 `.btn2` 回到 36px 触控地板。
